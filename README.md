# Celestial Companion

Loveable Prompt – Premium Notebook Brand Website

Project Overview

Create a premium, elegant, emotionally calming ecommerce website for a notebook brand. The entire brand identity should revolve around helping people who don't naturally fit into rigid productivity systems. This is not another productivity planner. It is a life companion designed for thoughtful people who think deeply, feel deeply, and want one beautiful place to organize everything in life.

The aesthetic should feel like a mix of:

Premium leather journals
